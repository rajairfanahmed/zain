# Muhammad Zain-Ul-Abideen Engineering Platform

Official domain glossary for Muhammad Zain-Ul-Abideen's multi-page Awwwards-tier engineering platform built for engineering managers and technical evaluators.

## Language

**Platform**:
The multi-page digital showcase and engineering dossier for Muhammad Zain-Ul-Abideen built on Next.js App Router.
_Avoid_: Personal website, resume site, generic portfolio, single-page flyer

**Route**:
A discrete canonical URL (`/`, `/about`, `/projects`, `/skills`, `/contact`) providing dedicated, shareable context for engineering hiring managers.
_Avoid_: Page anchor, hash section, single-page tab

**Engineering Manager**:
The primary evaluator reviewing system architecture, problem-solving depth, technical stack proficiency, and leadership impact.
_Avoid_: Casual visitor, generic recruiter, end-user

**Awwwards Craft**:
Bespoke visual and interaction design characterized by intentional typography, editorial layout rhythm, fluid transitions, and tactile micro-interactions.
_Avoid_: Template, cookie-cutter layout, generic bento box, AI slop

**Kinetic Monolith & Obsidian Specular**:
The visual language combining an ultra-deep obsidian/graphite canvas (`#07080B`), hairline rules (`1px`), high-contrast modern typography, and ambient lighting.
_Avoid_: Neon cyan glows, generic gradient blobs, flat grey cards

**Tri-Zone Navigation Bar**:
The persistent global header featuring the brand identity mark on the far left, centered canonical navigation links, and a highlighted "Resume" action button on the far right.
_Avoid_: Floating pill islands, hamburger-only desktop menus, crowded unaligned headers

**Executive Portrait**:
The art-directed monochrome portrait of Muhammad Zain (`zain.jpg`) integrated into the Hero stage and `/about` chronicle with subtle depth and entrance reveals.
_Avoid_: Generic avatar circles, unstyled stock frames, blurry thumbnails

**Curtain Route Transition**:
A synchronized, GPU-accelerated page transition sequence that elegantly unmasks new routes during navigation.
_Avoid_: Harsh page flashes, default browser reload delays, static jump cuts
