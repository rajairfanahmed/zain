# Multi-Page Next.js App Router Architecture

We decided to build Muhammad Zain-Ul-Abideen's Awwwards-tier engineering platform as a discrete multi-page application (`/`, `/about`, `/projects`, `/skills`, `/contact`) using Next.js App Router and TypeScript. This enables engineering managers and technical evaluators to directly share and bookmark specific chapters (e.g. deep-dive project case studies or technical skills matrices) with dedicated server-side OpenGraph and JSON-LD metadata, while maintaining seamless Awwwards-caliber page transition fluidity.
