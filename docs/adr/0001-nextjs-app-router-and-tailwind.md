# Next.js App Router, Tailwind CSS, GSAP, and Lenis

We decided to build Muhammad Zain-Ul-Abideen's platform using the latest Next.js App Router with Tailwind CSS, GSAP 3, and Lenis smooth scroll instead of a Webpack MPA setup. This provides clean canonical URLs (without `.html` extensions), native server-side metadata generation for company-level SEO, and seamless component-level styling with high-performance motion choreography.
